## Setup

### Windows

```powershell
python -m venv venv
venv\Scripts\Activate
pip install -r requirements.txt
python app.py
```

### Mac

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000/ in your browser.
